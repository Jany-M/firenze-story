# Firenze Story — Data sources register

**Living document.** Update it every time a source is evaluated, downloaded, processed or used in the build. Every dataset in the app must have a row here.
Background research: `docs/SOURCES-SURVEY.md`.

Project context: personal / cultural / educational, **non-commercial**. CC-BY-NC and "research use" licences are acceptable if attribution is given and the terms allow public non-commercial display. Always keep attribution.

**Status:** `candidate` (found, not evaluated) · `evaluating` · `requested` (asked the owner) · `acquired` (downloaded to `_dev/data/raw/`) · `processed` (in pipeline) · `in-use` (shipped in the app) · `rejected` (with reason)
**Confidence role:** what kind of evidence the source gives the model (`survey` = measured today, `cadastre`, `map-axonometric`, `view-perspective`, `archaeology`, `text`, `image-reference`)
