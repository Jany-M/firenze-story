# Firenze Story – web app

three.js 0.187 (WebGPURenderer + TSL, automatic WebGL2 fallback), Vite, TypeScript. Static site, no backend.

## Run
From the project root double-click **`start.bat`** (rebuilds stale assets first), or:
```
cd web
npm install --include=dev
npm run dev        # opens http://localhost:5173
```
`npm run build` produces a static `dist/` you can host anywhere (relative paths).

Documentation site (Zensical): built into `public/docs/` by `pipeline/prepare.py` and served at `/docs/` (also linked from Sources → Credits). Needs `zensical` in `.venv` once: `python -m venv .venv` then `.venv\Scripts\pip install zensical`.

URL switches: `?gl=1` force the WebGL2 backend · `?lite=1` no shadows, 1× pixel ratio (weak laptops).
The hash keeps the state (year, date, hour, mode, colour mode, overlay, camera), so any view can be bookmarked.

## Controls
- **View**: left drag move · right drag rotate · wheel zoom · **Ctrl + mouse rotate**, **Ctrl + Shift + mouse move**
  (no click) · W A S D move · Q / E rotate · R / F tilt · + / − zoom · N face north · **H** help panel.
- **Timeline** (bottom): drag, ← → one year, Shift ±25, Space play/pause, red pins = events, bars = construction dates
  (coloured = documented/inferred, grey = conjectural).
- **Modes** (top right): *Timeline* (miniature overview, tilt-shift) · *Live* (street level, people, scenes by date and
  hour) · *Sources* (colour by period or confidence, historic maps on the ground, events, credits).
- Click a building → card with dates, confidence, sources, Wikidata/Wikipedia links. The search box finds named buildings.
- Drop a Gaussian splat (.ply/.spz/.splat/.ksplat) on the page to place it at the focus point; permanent ones go in
  `public/data/splats.json`.

## Code map
| File | Role |
|---|---|
| `src/scene/city.ts` | all dated structures in one mesh; per-structure data textures (dates, façade layout, roof colour, material); TSL time filter, construction ramps, height caps; façades, roofs, colour modes; picking |
| `src/scene/environment.ts` | core + 12 km terrain, ground by era, Arno pools, weirs, dated bridge phases, vegetation by era |
| `src/scene/assets.ts` | shared textures; Blender props (materials rebuilt from `models/materials.json`) |
| `src/scene/view.ts` | view controls (Ctrl + mouse, keys, help panel) |
| `src/scene/stage.ts` | renderer, camera, sun and sky, haze, tilt-shift |
| `src/scene/splats.ts` | Gaussian splats |
| `src/sim/people.ts` | crowd on the street graph (era-filtered), costume kit binding, outfits by era and role |
| `src/sim/scenes.ts` | markets (Roman forum, Mercato Vecchio), calcio storico, Scoppio del Carro |
| `src/sim/river.ts` | boats, renaioli, fishermen, ferries, landing stages, wildlife, Iron Age huts (`RIVER_LIFE` table) |
| `src/ui/*`, `src/data/history.ts` | timeline, panels, inspector; epochs, events, palettes, credits |
| `public/*` | generated by `../pipeline` and `../blender/scripts` – do not edit by hand |
